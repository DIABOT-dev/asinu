# Asinu 2.0.4 — iOS Store assets

Prepared 16 November 2026 from app commit `f03d7f0c61d14dd721ee8d9a91064ee95a46c99a`.

These are native app screenshots from the Release simulator build, using current app screens and real backend routes with an isolated, fictional demonstration account. They contain no real patient records, real profile photos, or Care Circle QR links. The app UI has not been painted over or generated by AI.

| Directory | Device | PNG size | Count |
| --- | --- | --- | --- |
| `vi/iphone-6.9` | iPhone 17 Pro Max | 1320 × 2868 | 7 |
| `vi/ipad-13` | iPad Pro 13-inch | 2064 × 2752 | 7 |

Each set contains Home, the health calendar, today's medication reminders, daily medication schedules, the health journal, health coin tasks, and check-in body regions. Medication names, readings, progress, dates, and the name in the check-in greeting belong to the fictional demonstration data.

All files were checked for dimensions and RGB color mode, and reviewed visually for loading screens, error states, dialogs, and private data. SHA-256 values are in `screenshots-manifest.json`. Sizes follow [Apple's screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/).

Vietnamese and English release notes are included. These files are Store metadata, not application runtime assets.

## Upload status

**Prepared locally; not uploaded to App Store Connect.** Apple's API and the iOS submission both reject the account with `REQUIRED_AGREEMENTS_MISSING_OR_EXPIRED`. The Account Holder must resolve the outstanding agreement in [App Store Connect Business](https://appstoreconnect.apple.com/business), and, if requested by Apple, the [Developer account](https://developer.apple.com/account).

After that account issue is resolved, use iOS build **41**, version **2.0.4**, and verify the editable version, locale, and screenshot display types in App Store Connect before replacing its screenshot sets. Uploading a binary and submitting a version for App Review are separate steps; neither has succeeded for this release yet.
